# 블록크래프트

브라우저에서 바로 돌아가는 마인크래프트 스타일 복셀 게임입니다. 파일 하나(`index.html`)에 모든 코드가 들어 있고, Three.js(r128)만 CDN에서 불러옵니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## 기능

- 끝없이 생성되는 지형 (평야, 언덕, 눈 덮인 산, 바다, 모래사장, 숲)
- 16×16×64 청크 단위 생성/언로드, 면 컬링 + 앰비언트 오클루전 메싱
- 블록 14종 (모든 텍스처를 코드로 그린 16px 픽셀아트)
- 블록 부수기/놓기, 핫바 9칸, 블록 고르기 창
- 중력·충돌·점프·수영·비행
- 낮/밤 주기 (해, 달, 별, 흘러가는 구름)
- 수정한 세계를 브라우저(localStorage)에 자동 저장
- 휴대폰 터치 조작 지원

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 둘러보기 |
| 왼쪽 클릭 | 부수기 (누르고 있으면 연속) |
| 오른쪽 클릭 | 놓기 |
| Space | 점프 · 헤엄 · 비행 중 위로 |
| Shift | 달리기 · 비행 중 아래로 |
| F | 비행 켜기/끄기 |
| 1–9, 휠 | 블록 선택 |
| E | 블록 고르기 |
| Esc | 일시정지 |

# 첨탑을 오르는 자

슬레이 더 스파이어 스타일의 덱 빌딩 로그라이크입니다. `spire/index.html` 파일 하나로 돌아가며 외부 라이브러리 없이 구글 폰트만 불러옵니다.

## 실행

`spire/index.html`을 브라우저로 열면 됩니다.

## 기능

- 철갑 전사(체력 80, 에너지 3)로 두 막을 등반: 1막 지하 묘지 → 2막 도시 (각 15층 + 보스)
- 갈래길 지도 자동 생성: 적, 정예, 휴식, 상점, 미지(이벤트), 보물
- 카드 50종 (공격·스킬·파워·상태이상·저주), 모든 카드 강화 가능
- 힘·민첩·취약·약화·손상·혼란·금속화·소멸·휘발성 등 핵심 키워드
- 1막: 일반 적 10종, 정예 3종(그렘린 우두머리, 라가불린, 파수꾼 3기), 보스 2종(분열하는 슬라임 보스, 육각 유령)
- 2막: 일반 적 10종(흑조, 선택받은 자, 구체 수호자, 백부장과 신비술사, 스네코 등), 정예 2종(찌르기의 서, 노예 감독 무리), 보스 2종(절반 체력에서 분노하는 챔피언, 구체를 소환하는 청동 자동인형)
- 적의 의도 표시 (공격 수치는 힘·약화·취약까지 반영)
- 물약 11종: 슬롯 3칸, 전투 보상·상점·이벤트에서 획득. 상단의 병을 눌러 마시거나 버림
- 보스 처치 시 희귀 카드와 보스 유물(에너지 +1 대신 대가가 따르는 유물 등) 선택 후 다음 막으로, 체력 완전 회복
- 유물 23종, 이벤트 7종, 카드 제거·카드·물약·유물을 파는 상점, 모닥불 휴식/재련
- 휴대폰 화면 지원

## 조작

| 입력 | 동작 |
| --- | --- |
| 카드 클릭 | 사용 (대상이 필요하면 적을 클릭) |
| 1–9, 0 | 손의 n번째 카드 선택 |
| E | 턴 종료 |
| 상단 병 아이콘 | 물약 마시기 · 버리기 |
| Esc | 선택 취소 · 창 닫기 |
