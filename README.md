# 블록크래프트

브라우저에서 바로 돌아가는 마인크래프트 스타일 복셀 게임입니다. 파일 하나(`index.html`)에 모든 코드가 들어 있고, Three.js(r128)만 CDN에서 불러옵니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## 기능

- 끝없이 생성되는 지형 (평야, 언덕, 눈 덮인 산, 바다, 모래사장, 숲)
- 16×16×64 청크 단위 생성/언로드, 면 컬링 + 앰비언트 오클루전 메싱
- 블록 14종 (모든 텍스처를 코드로 그린 16px 픽셀아트)
- 블록 부수기/놓기, 핫바 9칸, 블록 고르기 창
- 중력·충돌·점프·수영·비행
- 낮/밤 주기 (해, 달, 별, 흘러가는 구름)
- 수정한 세계를 브라우저(localStorage)에 자동 저장
- 휴대폰 터치 조작 지원

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 둘러보기 |
| 왼쪽 클릭 | 부수기 (누르고 있으면 연속) |
| 오른쪽 클릭 | 놓기 |
| Space | 점프 · 헤엄 · 비행 중 위로 |
| Shift | 달리기 · 비행 중 아래로 |
| F | 비행 켜기/끄기 |
| 1–9, 휠 | 블록 선택 |
| E | 블록 고르기 |
| Esc | 일시정지 |
